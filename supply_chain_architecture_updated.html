★ Multi-Agent AI Layer
Layer 7 / Multi-Agent AI Pipeline — Demand & Risk Analysis LangGraph Orchestrated
How It Works
Raw signals from all upstream layers are funnelled into a 4-agent LangGraph pipeline. Each agent has one job: Fetch Agent collects & normalises data → Analyse Agent reasons across signals using an LLM → Risk Score Agent quantifies into weighted dimensions → Report Agent generates structured alerts. A confidence feedback loop between Analyse and Score agents ensures only high-confidence insights propagate downstream, targeting 90–95% prediction reliability.

Confidence Feedback Loop — Between Agent 2 & Agent 3
If the Analyse Agent returns confidence < threshold, the pipeline re-runs analysis with refined prompts, filtered inputs, and tighter reasoning constraints — before allowing the Risk Score Agent to proceed. This loop prevents weak or hallucinated insights from propagating downstream and is the primary mechanism for achieving 90–95% prediction reliability.
Loop: Analyse Agent → [confidence check] → if LOW → retry with refined prompt → Risk Score Agent
Per-Agent Responsibilities
📥 Fetch Agent
Parallel async calls to AISStream, OpenSky, GDELT, NewsAPI, EIA, Fake Store API, Yahoo Finance
Agent filters only relevant signals per region/SKU — discards noise before storage
Schema normalisation → unified JSON with region, event_type, severity, confidence
Data enrichment: maps regions → supply zones, SKUs → product categories
Writes only clean, relevant records to PostgreSQL — reduces model noise
🧠 Analyse Agent
Context aggregation: groups signals by region, product, time window
LLM reasoning (Gemini API): infers cross-signal relationships — e.g. demand spike + port strike + weather = supply-demand imbalance
Structured prompt extracts: risk type, root causes, affected regions, impact duration
Outputs confidence score per analysis — triggers loop if below threshold
Writes structured analysis JSON to state["analysis"]
⚖️ Risk Score Agent
4-dimension scoring: Supply · Demand · Geopolitical · Logistics (each 0–1)
Weighted aggregation: 0.3×Supply + 0.3×Demand + 0.2×Geo + 0.2×Logistics
Severity classification: Critical (>0.75) · Medium (0.4–0.75) · Low (<0.4)
Only accepts analysis with high confidence from Agent 2 — else triggers retry loop
Writes scores to state["scores"] → feeds ML models & Report Agent
📢 Report Agent
LLM-generated summary (Gemini API): plain-English alert narrative per risk event
Recommendation engine: ranks mitigation actions by impact & urgency
Multi-format output: JSON for system integration + NL for Slack/email
Routing logic: Critical → immediate ops escalation · Medium → planning (24h) · Low → weekly digest
Writes to state["alerts"] → triggers Smart Alert Engine & Autonomous PO Agent
